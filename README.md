# Links · Nicolas Schulze

Página de links para a bio do Instagram e para mandar para as pessoas. Ela segue o design system da marca: monograma N, Barlow Condensed e o acento roxo da série Estudos. Tem modo claro e modo escuro.

**Endereço:** https://nicschulze123-sudo.github.io/links/

## Arquivos

| Arquivo | O que é |
| --- | --- |
| `index.html` | A página inteira. Os links ficam aqui. |
| `house-farm.jpg` | Foto do projeto em destaque. |
| `preview.jpg` | Imagem que aparece quando o link é colado no WhatsApp, no LinkedIn etc. |
| `logo.svg` | Ícone da aba do navegador. |

## Como editar um link

1. Abra `index.html` aqui no GitHub e clique no lápis (Edit).
2. Procure o bloco `LINKS` e troque o `href="..."` do botão.
3. Clique em **Commit changes**. A página atualiza sozinha em cerca de 1 minuto.

Para ativar o YouTube, apague a linha com `em breve` e tire o `<!--` e o `-->` da linha de baixo, colocando o endereço do seu canal.
